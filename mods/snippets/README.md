# Сниппеты для Herdr

Скопируй мод в `~/.config/herdr-app/mods/snippets/` и добавь команду из
`keys.json` в раздел `global` настроек клавиш Herdr. Для вставки нужен
установленный Herdr Gitview.

Создай каталог `~/.config/herdr-app/snippets/`. Добавь, например,
`commit.md` и запиши в него текст промпта. Название файла задаёт имя
сниппета. Herdr перечитывает список при открытии, а текст при выборе.

Последний успешно вставленный сниппет стоит первым. Неиспользованные идут по алфавиту. При поиске сначала учитывается качество совпадения, затем давность вставки. Мод хранит локально только имена файлов, а не их содержимое.

**Cmd+Shift+S** открывает поиск из терминала. **↑** и **↓** меняют выбор,
**Enter** или клик вставляет текст в исходный терминал. **Esc** закрывает список.
Для текста с несколькими строками терминальная программа должна поддерживать
вставку многострочного текста без отправки. Вставка сохраняет переводы строк
внутри текста и убирает пустые строки в конце.
